# E1124｜真实表征怎样指导层间学习，训练捷径又应在哪里受到限制？

**正式实验方案 · 2026-11-25，2026-11-26 接入实现。** E1124 采用完整 23 组，训练种子固定为 1024，三条路线同时列入计划。每组使用同一协议完成八库评测；B00、P128F 对齐历史产物后可复用，预计需要 21 次新训练。正式训练及终评待运行。

## 1. 完整方案的三条研究路线

| 路线 | 出发点 | 这次可以检验的主张 | 决定性比较 |
|---|---|---|---|
| A · 延续 E1119 | 用真实人脸的表征指导单层更新，以及后一层如何读取前一层的更新 | 真实参照有可能在**选择性传递新写入的信息**时比随机、一般人脸参照或等强度衰减更有效，即使全层硬保护表现欠佳 | 单层看 P128F 与历史 P02/P03/P04；层间看 L1 对 B00、L2、L3、L4，前向与反传看 L1 对 L5 |
| B · 迁移 VETO | 先构造能够暴露可疑线索的参考条件，再限制 LoRA 沿这些方向更新 | 同内容、同帧、同为假脸时，四种训练伪造之间的变化可用来定位一部分方法依赖；限制这些变化可能有利于迁移 | V95 对 V95R 测直接类比；N1 对 N0/N2/B00 测方法差参考；N3 对 N1/N4 测保留共同真假证据 |
| C · 综合两条路线 | 同一个检测器中，分别控制“本层能沿哪些方向更新”和“下层能读到上层哪部分新增响应” | 两项约束可能分别有效、相加、互补，也可能重复压制同一信号。组合是否值得由各自的边际收益决定 | B00、L1、N1、C1 四格对照；C2、C3 分别替换其中一种参照 |

**三条路线在同一批实验中评估。** 分别比较 A 与 B 的单项效果，再用四格对照读出 C 的组合增量。这里的先后是结果解释顺序，各组独立按依赖就绪情况运行。

### E1119 确立的研究前提

**以真实人脸的表征为参照，重新设计强基线在训练中可以改变哪些特征、这些变化如何在层间传递，从而让模型在 FF++ 上学到的判别依据能够迁移到未见数据集和伪造方法。** B0 已有一部分跨库能力。FF++ 监督可能同时写入源域特有的线索，而后续层可能继续利用或强化这些变化。后两点属于研究假设；真实主方向是否含有应保留的信息、哪些层确实依赖它们，都需要对照回答。[E1119 原始方法与判读规则](E1119_README.md)

E1124 保留 B00 的完整 Q/K/V/O 适配。真实、随机和混合来源提供匹配对照，固定适配位置后再比较前向读取与梯度路径。E1115 的配对差只用于路线 B 的固定基构造，正式预测由原分类头给出。

## 2. VETO 可以迁移哪一部分

VETO 研究视频问答的监督微调。拿走视频以后，模型仍能借问题与选项的规律改善答题。作者用冻结模型读取纯文本输入，在各适配模块收集输入激活的**未中心化二阶矩**，用累计能量 95% 决定每层的受限维数。在初始化和每次优化器更新后投影 LoRA 的输入因子 A，保留优化器动量。以论文表 5 的 Qwen2.5-VL-7B 为例，完整输入准确率从普通微调的 89.6% 变为 89.2%，纯文本相对基座的准确率增益从 +30.5 降至 +6.0 pp。作者由此用同一个实验区分“保住任务收益”和“减少缺失视频时的收益”。[论文 §3、表 5–6 和附录 D](https://arxiv.org/html/2611.25776v1) · [作者实现](https://github.com/Youngwoo-git/VETO) · [用户提供的 OpenReview 条目](https://openreview.net/forum?id=PPII4JrkqX)

**可直接迁移的是对 LoRA 更新的限制。需要重新设计的是如何识别可疑方向。** 我们的 CLIP 逐帧读一张脸，没有可以拿掉视频后保留的问题文本。真实人脸是负类本身，真假共享的脸部结构也可能是判断编辑痕迹所需的参照。把纯文本换成真脸，是合理的迁移对照，但两者的因果含义不同。

| 工作 | 用什么确定子空间 | 限制的对象与仍待回答的问题 |
|---|---|---|
| Effort | 冻结预训练权重的主奇异分量 | 保留主分量，适配剩余分量。它回答如何保留预训练结构；E1119 的 M01/M02 同时改变了参数化，不能单独估计“给相同 LoRA 选哪组方向”的效果。[Effort，ICML 2025](https://proceedings.mlr.press/v267/yan25b.html) |
| OPLoRA | 权重的左右主奇异向量 | 在标准 LoRA 两侧作投影，以减少遗忘。“Effort 式谱保护加到 LoRA”已有直接先例，可作强对照。[OPLoRA，AAAI 2026](https://arxiv.org/abs/2510.13003) |
| VETO | 去掉视频后仍存在的文本激活 | 限制 LoRA 对该输入子空间的直接响应。有可观测的缺证据任务，且有随机子空间对照。[VETO](https://arxiv.org/html/2611.25776v1) |
| GSD | 冻结 CLIP 估计的优势语义方向 | 已在生成图像检测中研究语义捷径，按样本和层调节抑制。把“抑制语义促进泛化”作为总体动机已有充分先例。[GSD 原文](https://arxiv.org/abs/2603.09242) |
| 本项目 | E1119 P 族为真、假、混合或随机参考。E1124 分别研究真实参照引导的层间读取、同内容不同伪造方法构造的更新约束以及二者的组合 | 可以检验究竟是通用语义、受限容量，还是 FF++ 中具体方法间的变化在起作用。若同维随机约束同样好，就应保留容量解释。 |

列向量记法下，标准 LoRA 为 `W_eff = W₀ + sBA`，`s=α/r=4`。给输入侧的正交基 U，VETO 的操作为 `A ← A − (AU)Uᵀ`，因而 `ΔW U = 0`。原预训练主路仍接收完整输入。E1119 的 LoRA 包装器在内部以 `[d_in,r]` 存储 A 的转置，在每次前向和折叠时计算 `a_eff = a − U(Uᵀa)`。两者具有相同的前向可表达集合；逐步投影实际权重与前向重参数化对 Adam 的逐坐标梯度和动量作用不同。固定同一组 U 才能比较执行方式。路线 B 的投影只限制直接线性更新，深层输入和分类头仍可间接响应这些方向。[本地 LoRA 实现](../training/e1119_model.py) · [原生适配器](../training/detectors/effort_detector.py)

## 3. 离线材料与划分

### 3.1 真实激活统计

复用 E1119 的真实参考和确定性输入变换。Q/K/V 共享同一输入统计点，O 使用该层输出投影的实际输入。V95 重算未中心化二阶矩并按各点的特征谱确定维数，V95R 使用同维随机基。[资产实现](e1124_assets.py)

### 3.2 FF++ 测试诊断

在 FF++ test 按双序列编号匹配四种伪造和对应原片，报告各方法的真假 AUC、平均分数差和组内分数散布。以平均帧 logit 差和视频概率两种口径报告，便于判断概率饱和对读数的影响。

### 3.3 FF++ 训练帧配对清单

按 FF++ train/c23 的原生前 8 个索引帧，选取原片和四种方法之间至少有两个共同帧号的条目。将同一对序列的正反方向归入一组，用排序后的双序列键取 SHA-256 并按 80/20 划分。该索引对应 67 个拟合组与 17 个留出组，分别有 348 和 87 个对齐时刻，两组序列 ID 无交集。正式训练仍使用完整 FF++ train。共同帧号来自原生人脸裁剪，机制读数按目标序列等权。

运行入口从输入指纹已核对的 FF++ 索引重建清单，并在运行目录保存 `pair_manifest.json`。也可以传入历史清单复核各组和逐帧映射。[配对实现](e1124_assets.py)

## 4. 三条路线的模型、预期价值与成立条件

### 4.1 路线 A：用真实参照选择下一层能读取的更新

E1119 的 P 族保护整层输入子空间，I 族改变前一层新增响应是否进入后一层增量。**L1 只干预第 23→24 层这一条连接。** 第 24 层仍能接收完整人脸信息；我们只问，它的适配器是否需要再次利用第 23 层刚沿真实参考方向写入的变化。选择末对是为了直接接续既有 I01/I03 对照，并把重复计算限制在一块。

令 h 为第 23 块入口，同一 h 分别通过该块适配器开启、关闭的完整计算得到 v、u。令 nᵥ=LN₂₄(v)、nᵤ=LN₂₄(u)、δ=nᵥ−nᵤ。U_R 为**接收层**预训练 CLIP 的 Q/K/V 输入上由 E1119 真实参考估计的 top-128 基，P_R=U_R U_Rᵀ。以下式子对所有 token 生效。第 24 层 Q/K/V 的主路和增量分别计算 `W₀ nᵥ + b + ΔW t`，其 O 投影、残差、MLP、原头和其余层遵循原生规则。

| ID | 增量读取 t | 回答什么 |
|---|---|---|
| L1 | nᵥ−P_Rδ | 保留原输入中已有的真实方向信息，限制本次新增响应中落在这些方向上的部分；全体样本仍只用 CE |
| L2 | nᵥ−P_Zδ，同维随机基 | 收益是否只来自少传一些自由度 |
| L3 | nᵥ−P_mixδ，同维、相同材料预算的 E1119 混合人脸基 | 高能人脸方向与真实参考的效果能否区分 |
| L4 | nᵥ−cδ，逐 token 取 c=‖P_Rδ‖/‖δ‖，零范数时取 0 | 在相同权重和输入下移除等长向量，但沿 δ 均匀衰减。检验移除的方向是否比移除量重要。非零范数处按公式求导 |
| L5 | nᵥ−P_Rδ+stopgrad(P_Rδ) | 前向值仍是 nᵥ，训练时切断 P_Rδ 这部分直接读取的梯度。与 L1 对照两种完整学习规则 |

P=0 恢复普通读取，P=I 恢复 I01 的全量参考读取。L1 本身不约束 ΔWU_R=0，它只改变接收层适配器的输入。u 与 v 都由同一 h 计算，只旁路第 23 层的适配器；参考分支对 h 保持可导。L5 在训练时需要参考计算，推理时用标准 24 块。L1–L4 训练及推理需要额外计算一次第 23 块，并保留接收层双输入 Q/K/V；应报告实测耗时。L1 与 L5 的差异包括学习到的权重，不能将两者的 AUC 差解释为一个孤立的梯度因果量。

**层间响应读数。** 按类别计算 `E‖ΔWδ‖² / (E‖ΔW nᵥ‖²+10⁻⁸)`，再比较不同读取规则。响应反映后层增量对前层变化的敏感程度；外库 AUC 与真假分数差用于判断这种变化是否有利于检测。[计算实现](e1124_analysis.py)

**成立条件。** L1 胜 B00 说明完整方案有净收益；胜 L2 和 L4 才支持方向选择有额外价值；胜 L3 才支持采用真实参考优于一般人脸参考。若 L1 和 L3 接近，结合两基重叠与移除能量判断，本轮可以得到“共享的人脸方向足以解释结果”的结论。L1 与 L5 的差别决定部署时多算一块值不值得。

### 4.2 路线 B：用同内容的多方法差异定义 VETO 的视觉参照

**假设。** 固定原片、时刻和真假标签后，四种编辑算法造成的部分变化，是训练环境特有的加工方式。若 LoRA 主要依靠它们写入判别能力，就可能在陌生来源上失效。另一种同样具体的可能是，这些方向正包含最清楚的篡改证据；限制它们就会同时损伤已知与未知伪造检测。两种结果对方法设计有不同含义。

**构造固定基。** 在冻结、eval 模式的 CLIP 上，仅使用 §3.3 拟合组和既有确定性评测变换。每层在 attention 的 Q/K/V 前和独立的 O 前各取一次输入。将每帧的 256 个 patch token 取平均得到 1024 维向量，去掉 CLS，避免把裁剪位置差直接当作同一 patch 的变化；这也可能削弱小面积篡改，留出诊断会反映这种代价。基拟合用帧均值，前向约束作用于该投影的所有 token，包括 CLS。

对于某个原片与共同帧号，令 r 为真实向量，f₁…f₄ 为四种伪造。定义

- `μF = (f₁+f₂+f₃+f₄)/4`，`dₘ = fₘ − μF`。四个 dₘ 的标签相同，描述同一时刻的方法间变化。
- `g = μF − r` 描述平均伪造相对真实的变化。按方法等权，`meanₘ[(fₘ−r)(fₘ−r)ᵀ] = ggᵀ + meanₘ[dₘdₘᵀ]`。两项的交叉项在组内抵消，**这不等于两个子空间天然正交**。
- `C_M = E[meanₘ dₘdₘᵀ]`、`C_G = E[ggᵀ]`。先等权平均每个目标序列内的共同帧，再等权平均目标序列。对每个统计点分别拟合，缓冲区训练期间固定。留出组不参与特征分解。

**两个完整模型。** N1 取 C_M 的前 16 个特征向量作为 U，用 VETO 式逐步投影训练原 LoRA 和原头。N3 先取 C_G 的前 4 个方向 V，令 `H=I−VVᵀ`，用 `H C_M H` 的前 16 个正特征方向作为 U。这样只在 V 的正交补内寻找要限制的方向，LoRA 仍可沿这 4 个共同真假方向学习。16 与 4 是本轮预设的低维设计值，均不按六库表现挑选。N3 的主要风险是把四种方法共有的压缩、渲染或裁剪特征也当成应保留的证据；它与 N1 及随机 V 的对照可以检验这一点。

**该想法的差异与新增价值。** 判别参照从“真脸经常出现什么”变为“同一内容保持假标签时，替换编辑方法会改变什么”。这样能用同一批实际样本，把算法间变化与平均真假变化明确分解。若 1024 下 N1 或 N3 优于同秩随机、同材料真实参考和 B00，且优势见于多个外库，同时保住真假间隔，才有证据把改善归于这种参考构造。即使只改善方法间一致性，仍可报告它改变了哪种行为，但研究主目标仍以未见来源表现判定。

### 4.3 路线 C：把单层更新约束与选择性传递放入同一检测器

C1 事先固定为 **N1 + L1**。N1 在每层用已知方法差基 U_M 限制 LoRA 的直接权重更新；L1 只在末对连接，用真实参考 U_R 决定前层新增响应的哪部分交给接收层适配器。把两项作用写到一个式子里，第 24 层 Q/K/V 的有效增量为 `sBA(I−P_M)(nᵥ−P_Rδ)`，这里 A 表示投影前因子，实际参数按 N1 的逐步投影实现。顺序是先形成读取值，再以受限权重作用于它。C2 用 N0 的同维随机基替代 N1；C3 保留 N1，用 L2 的随机读取替代 L1。C 行都按自己的学习规则从预训练 CLIP 完整训练。

**为什么不能随手叠加？** 若把同一个正交基既用于接收层的硬更新约束，又用于过滤传入增量，`ΔWP_R=0` 已让层间过滤项恒为零。此时给定权重的前向输出与单层方案相同。逐步投影配合 Adam 仍可能改变优化轨迹，因此一次重训分差也不足以说明有新的前向传递作用。C1 使用分别估计的两个基，仍要在第 24 层报告 `‖U_MᵀU_R‖²_F / min(k_M,k_R)`，以及同一输入上过滤前后实际响应差 `ΔW P_Rδ` 的能量。前者反映几何重叠，后者才反映模型是否真的感受到第二个操作。以同基和零投影作离线算子校验。

记 S 为同一 seed 的六库视频 AUC。C1−N1 是已有单层约束时增加真实参照传递的收益；C1−L1 是已有真实参照传递时增加方法差约束的收益；交互量为 `S(C1)−S(N1)−S(L1)+S(B00)`。两项都正、组合胜过两个单项，即可说明组合在本协议下实用；只有交互量也有相应证据，才讨论超出加和的协同。交互为正而 C1 仍低于 B00，仍应报告净损失。C1 对 C2/C3 检验在组合内替换各自参照的影响。若组合没有增量，A 或 B 仍可独立采用。

| 推理与导出 | 沿用 `e1119_eval.native_loader`、原分类头和历史导出接口。逐帧输出假类概率 `softmax(logits)[1]`，保持路径、标签、完整视频 ID 与行顺序；每库保存原结构的 `frames.npz`、`videos.npz` 和 `metrics.json`。视频表沿用 `video_id/label/prob_fake/frame_count`，`prob_fake` 为该完整路径视频各帧假类概率的算术均值。 |
| 汇总 | 用 `readout_metrics(values, values["cls_prob"])` 计算历史指标，保留帧 AUC、逐库完整路径视频 AUC、七库和独立六库等权均值，以及按 basename 的历史兼容列。FF++ 不计入七库，参与选点的 Celeb-DF-v2 再从六库排除。缺库时保留状态和缺项，完整均值留空。 |

允许变化的是注册表逐行定义的模型更新与层间读取规则。保存每行解析配置及其相对 B0_NATIVE 的差异、输入与固定资产指纹、best 的选点记录、逐帧及逐视频产物。模型机制读数另存；正式原头输出和跨库主表沿用上述路径。[原训练配置](run_e1115.py) · [E1119 配置与调度](run_e1119.py) · [原生八库评测及导出](e1119_eval.py)

**估计和执行。** V95 的后段 k 超过 128，不能把 E1119 已存的 128 列基直接切片扩充。应从冻结骨干重新用 P01 的 references 清单累积完整二阶矩，核对重算的 top-128 子空间、能量谱和 token 数，再输出各点的 k 与正交基。新随机基由 1024 与参照种类、层号、统计点确定性派生，使用独立生成器。组合直接复用相应单项的同一份基。用于历史比较的 P01/P04 真实或混合统计资产沿用原文件和哈希。N3/N4 核对 `‖VᵀU‖`、各基的正交误差和正谱数；不足 16 个可辨识方向时记为该规格不可估，不用零谱或随机方向凑数。

路线 B/C 的配对材料用于训练前的固定基估计及留出读数，路线 A 单独训练时无需四方法配对。正式训练仍从原 loader 接收单帧，按原整批 CE 优化；推理只需单个视频，无配对原片、方法标签、目标域真实样本、第二个头或外置融合。

所有新行以 E1115 B0_NATIVE 配置的预训练 CLIP 重新初始化。四投影 24 层，普通 r=4、α=16，变秩行 α=4r；LoRA 的总可训练参数均为 786,432，另有相同的 2,050 个头参数。R1/R2 的 rank 6 要创建真正的 6 维因子。现有 E1119 包装器只从原生 rank 4 参数切片，不能拿来直接构造 6。为变秩行按原 loralib 规则初始化对应形状的 A、令 B=0，固定头和数据 RNG，并记录解析配置。参数数相同不等于可用输入维数、时间和显存都相同。

逐步投影用现有 Adam，每次实际完成参数更新后以 FP32 在 no-grad 下投影参数并原位写回，跳过 AMP 未执行的更新；保留原优化器状态与参数对象。按原生 `A[r,d]` 写 `A−(AU)Uᵀ`；若用包装器的转置存储则写 `a−U(Uᵀa)`。除 P128F 外，逐步投影行前向用已投影参数；不得再叠加前向投影。单输入投影部署可折叠为 `W₀+sBA`。L1–L4 和 C1–C3 的第 24 层 Q/K/V 是双输入，对应算子保留参考分支；L5 在推理时恢复单输入。实现时验证初始 logits 与基线相符、投影后 ΔWU 残差及折叠前后原头概率误差。保留实际步数、耗时、峰值显存和资产哈希。[配置与调度入口](run_e1119.py) · [激活统计](e1119_assets.py) · [模型实现](../training/e1119_model.py)

## 6. 如何评价新增价值

**检测主结果。** 继承 FF++ c23、原 sampler、每批 10 真/22 假、原增强及原生 8 帧、11 轮 6,325 步。沿用 CDF-v2 帧 AUC 选择 checkpoint。同一 checkpoint 在八库终评，逐帧 softmax 假类概率按完整视频路径平均。独立六库 WDF、FFIW、DFD、DFDC、DFDCP、DeeperForensics 等权；CDF-v2 和 FF++ 单列。主表报告每个配置的 seed 1024 八库结果、六库均值和相对 B00/1024 的差值。区间描述给定权重在测试视频上的抽样不确定性；本轮不估计训练随机性。按原协议对预定对照做库内真假分层、视频配对的 2,000 次 bootstrap。算术交互也在同一抽样索引上计算。训练配方与评估由既有入口生成。[历史评测与区间实现](e1119_report.py)

**机制结果。** 在 17 组源域统计留出材料上分别算 `tr(UᵀC_M U)/tr(C_M)` 和 `tr(UᵀC_G U)/tr(C_G)`，两个矩阵均用留出数据重估。与 N0/N2 比，看 U 是否更集中覆盖方法差；N3 对 N1 看误伤共同真假差是否减少。对施加硬更新约束的行记录实际 `‖ΔWU‖F/(‖ΔW‖F+ε)`。对 L/C 行，复用同一模型的权重和末对输入计算 §4.1 的响应，并报告真实与伪造两类的 `E‖ΔWPδ‖²` 和归一化分母。L4 用 cδ。L5 单列潜在前向响应与实际前向响应；后者与相同权重的完整读取一致。FF++ test 在 §3.2 的 140 个完整组合上比较四方法各自对同组真实视频的 AUC、真假间隔和组内方法分数散布，同时给出均值和最弱方法。报告假类概率与视频均值帧 logit 差两种读数，防止仅凭概率饱和宣布方法不变性。留出材料仅独立于拟合固定基，不用来证明骨干跨域泛化。

**如何检验“源域强化、跨域受损”。** 对每个 L/C 的 best，在相同原生视频上并列记录其实际规则与临时恢复完整读取的原头视频分数。给出 FF++ 四种方法各自对同组真实视频的 AUC、真假分数间隔、独立六库逐库 AUC 及两种读取规则间的变化。L5 的固定权重前向消融按构造应为零，其优化效果用独立训练的 B00 作对照。若完整读取在 FF++ 增大方法分差，并在源域有利、外库有害，才有直接迹象支持该连接上的源域偏好；若两边都变差，应考虑有用线索被误伤。在单条边上观察到这种现象仍不能推出整个 24 层都逐级强化。D01 的逐层可读性、D02 的关闭干预、D03 的真假漂移分别解释表征、依赖与保持程度，不用探针代替原头选点。

**判读约定。**

- V95 与 V95R 一起变差，优先解释为封掉的维数过多。若 V95 优于 V95R 而落后于 B00，说明方向有信息，但直接迁移仍有净代价。
- N1 比 N0/N2 更覆盖留出方法差，却降低外库 AUC，说明该差异中含可迁移证据，或剪掉它的代价太高。若只缩小四法分差且真假间隔同步缩小，应报告检测能力收缩。
- N3 同时优于 N1 和 N4，且留出共同差保留较多，才支持保护这些特定真假方向。只有六库 AUC 上升而机制指标不动，可以报告模型收益，原因另查。
- R1 胜 R2 但未胜 B00，只能说明同预算下位置重要。X1 若没有超过两个单项，应按实际增量决定是否值得合并。各方向失败不取消其余预先登记行。
- 六库同时改变来源、采集、压缩和伪造技术，能检验现有跨库协议的泛化，无法单独归因于“未见算法”。若形成论文主张，优先在**此前未用于方向选择**且伪造方法来源可核实的新库上确认，分别报告未见方法/新来源切片。另做 FF++ 留一伪造法重训可专门检验未知方法，但会改变历史训练集，应独立立项并在每折重新拟合基，避免把被留出的方法用于离线统计。

**执行与完成条件。** 全部 23 行以正式数据、全训练预算和完整八库评测一次登记。固定资产可并行准备，R1/R2 等无资产依赖的行可直接训练。开发实验、冒烟测试、小样本试跑和按前序成绩筛选后续配置均不设为阶段。原 Trainer 的验证选点、正式产物的输入输出对齐核对照常进行。每行记录完成、失败或缺库状态；全部 23 行各有可对齐的八库结果（共 184 个配置–数据集结果）后，才将全实验记为完成。

**历史产物复用。** 在输入指纹一致的前提下核对历史配置、checkpoint 记录和原生预测导出。需要加载历史权重的分析使用 SHA-256 一致的归档副本。

**完整方案内的优先级。** A 和 B 并列推进。A 首先回答真实方向是否能指导有选择的层间协作；若 L1 相对随机有效但与混合基持平，后续重点宜转向共享人脸结构。B 首先回答源域方法差是否值得限制；若 N1 损伤真假间隔，N3/N4 可以判断显式留出共同真假方向能否补救。C 是独立的组合检验，结果按边际增益、交互及额外推理成本判读。已有正交约束方法提供的是可用的工具和对照；本项目可检验的贡献在于参照从何而来、该约束在哪一层计算中发挥作用，以及这能否改善未见域上的检测。

## 7. 完整实验入口

从 DeepfakeBench 根目录运行。E1119 路径指向含 `inputs.json`、`queue.json` 和原始激活资产的历史运行目录。启动时按 §3.3 重建配对清单。

```bash
python experiments/run_e1124.py \
  --e1119-root /path/to/experiment_results/E1119/RUN_ID
```

若路径与 E1119 的默认设置不同，可传入 `--rgb_root`、`--dataset_json_folder` 和 `--clip_pretrained_path`，解析后仍须与归档输入指纹一致。通过 `--gpus 0,1` 指定 GPU；省略时使用当前可见 GPU。启动时解析和校验原始数据及权重，依照固定资产和 checkpoint 依赖运行完整队列。

`--plan` 只列出注册配置和依赖图。使用相同参数重新运行时，队列在同一指纹目录复用成功任务，并为未完成任务创建新的尝试目录。

默认产物目录为 `experiment_results/E1124/<run_id>/`。其中 `main_seed1024.csv`、`datasets.csv` 和 `protocol_alignment.csv` 分别记录主表、八库明细及输入输出对齐。方法配对读数在 `matched_ffpp.json`，AUC 差及 C1/X1 交互的配对区间在 `paired_bootstrap.csv`，整体状态在 `completion.json`。每个配置仍可从队列查到原生训练配置、checkpoint 记录、逐帧和逐视频预测及机制分析。
