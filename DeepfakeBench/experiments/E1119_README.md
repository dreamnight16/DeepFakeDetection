# E1119｜强基线深伪检测：模型适配、真实表示保护与层间传递

**交付状态：已实现全量入口，等待在正式数据和 GPU 环境运行。** 本文规定实验设计。运行范围按最终决定：只改模型。所有登记行一次编入同一批队列，独立完整训练；不存在冒烟、小样本、开发试跑、按成绩放行、赢家再复跑的阶段。原 Trainer 的选 checkpoint 不属于新增开发实验。

## 1. 实验问题与总预算

1. FF++ 微调需要学习新方向、旋转方向，还是只调预训练变换的强度？比较 LoRA、Effort、LN、奇异值、旋转和随机基。
2. 在相同更新自由度下，用真实人脸、假脸、混合样本或随机数定义“不可直接改写的方向”，跨库效果有何差别？
3. 保住真实样本穿过一个层段时的变换，与对所有样本冻结该层段，有何差别？
4. 参数量不变时，后一层的适配是否应该直接读取前一层刚写入的变化？改变前向信息与只断开反向梯度，哪个有用？

**23 种独立检测方法 × 2 个训练种子（1024、1025）＝46 次完整训练，46 套八库终评。** 两个种子均覆盖全部配置，不根据首种子结果决定第二批。B00 是各族共用的一行，不重复计数。另有同批的冻结模型读出/干预分析，不计作新骨干训练。全部指所有登记方法和对照同时列入计划，不做跨族任意笛卡尔积；否则无法定位增益。实际并发由拿到的 GPU 数决定，每卡一个完整训练进程，单卡也能顺序跑完。

## 2. 所有训练共用的条件

- 以 E1115 的 **B0_NATIVE** 而非其 FULL_REAL70_COVERAGE 为底稿。FF++ c23、原图像索引和增强、原训练/测试每视频 8 帧、224×224、原 sampler real ratio=0.30（batch 32 为 10 真/22 假）、batch=32；不更换采样器，不改数据读取失败行为，不改裁剪、插值、视频 ID 或取帧顺序。无 mixup、频率支路、多裁剪、测试时自适应、配对训练或新视图。
- 同一份 CLIP ViT-L/14 预训练视觉塔，同一原生 pooled CLS → Linear(1024,2)，0 真、1 假。每行从预训练 CLIP 独立初始化，**不从已训 B0 拔适配器**。同一种子显式共用头部初始状态及 loader 随机设置，SVD、随机基、统计和日志不消耗训练 RNG。以源配置的头、偏置、优化器分组为准，不以类名“effort”判方法。
- 原 Adam，学习率 2e-4、weight decay 5e-4、epoch 0–10 共 11 轮；其他调度、AMP、验证频率、Adam 参数继承并保存完整解析配置。共同使用整批 CE，仅 M02、T01、T02 有表内声明的辅助项。M03 不引入 GenD 的球面损失和数据配对。使用同一学习率是本轮固定训练预算下的比较，不声称每种参数化都已调至最优。
- 继承现有 CDF-v2 frame-AUC 选点；每行在该规则下产生一个 best，同时保存 epoch 0、5、10 结束时权重。CDF-v2 单列为见过的选点域，不能进独立六库均值。禁止用六库结果调学习率、方向维数、层号、正则权重或重选 checkpoint。
- 本文层号从 1 起。代码 blocks[0:24]；17–24 对应 [16:24]，23→24 对应 (22,23)，15→16 对应 (14,15)。宽 d=1024，24 层；96 个原注意力方阵。列向量写 y=Wx+b；在 PyTorch 用 linear(x,W,b)，不要把论文里的投影乘错一侧。

### 从输入到视频判决：23 种方法共用的检测器定义

每个 ID 都训练出一个能单独对新视频作出判决的模型。无需输入标签、来源库、真假配对或原始未篡改视频。公共计算链如下，后文各方法只替换标明的算子：

1. 原生 loader 给出图像；CLIP 的 14×14 patch 嵌入、位置嵌入和 CLS 产生 257 个 1024 维 token。记进入第 ℓ 个块的整段序列为 H。Q/K/V 从该块前置 LN 的输出生成；按原模型拆头，头内计算 softmax(QKᵀ/√d_head)V，经原 O 投影写回残差流，随后经过原 pre-LN MLP 和第二条残差。所有方法保留预训练的 CLS、位置编码、MLP 和完整 24 块深度；T03 冻结末段但不删层。仅 M03 学习 LN 仿射参数。
2. 每张图的输出固定为 z=postLN(H₂₄[CLS])、两类 logits=Cz+c、p_fake=softmax(logits)[1]。CE 在每个原生 batch 的全部样本上求均值。普通方法直接优化 CE；M02 改权重目标，T01/T02 加输入条件的函数约束，I03/I05 改反传算子。**训练谁、读什么、在哪儿阻断梯度，是不同的设计选择。**
3. 所有方法都以自己的 best 权重走同一条八库评测链：每视频平均原生 8 帧的 p_fake 后作排序。P 族的参考统计、M 族的矩阵基和 I 族的成对连接是模型定义的一部分，不是第二个打分器。辅助分析不参与判决或选点。

§3–7 给出一组完整模型的构造、学习、推理和判读。基线与匹配对照也按同样标准交付，但不为使其“像新方法”而附加损失或重新取名。

## 3. B 族：原 B0、容量与位置

B00 使用原 effort_detector.py 的实际实现：冻结预训练视觉塔；Q/K/V/out 四个 Linear 保留原 W、b，更新 W_eff=W+(α/r)BA，无 LoRA dropout，A 正常初始化、B=0；保持原 head。B01 不创建适配，不训练任何 LN。B02/B03 除目标位置外全部使用原始冻结 Linear。B00/02/03 为 r=4, α=16；B04 为 r=2, α=8。均保持 α/r=4。

不含共同的 2,050 个头参数，B00 有 786,432 个可训练参数；B02/B03/B04 均为 393,216。冻结 Q/K 并不等于固定注意力图：前层改变后，Q/K 的输入仍可变。B02、B03、B04 可两两等参数比较；与 B00 比时自由参数数目同时改变。

### 五种完整注意力适配方案

| 方法 | 从输入到判决的机制，以及要验证的预测 |
|---|---|
| B00：联合学习路由与内容 | 每层同时调整 Q/K 的相似度计算、V 携带的信息及 O 写回残差的方式；CE 从最终 CLS 到全部 96 个低秩增量以及原头。它是待超越的强模型，不是假定已经过拟合的负例。 |
| B01：冻结表示读出 | 整个视觉塔作为固定函数，CE 只学习两个类别在 pooled CLS 上的线性边界；部署不需要适配器。如果它在外部库接近 B00 而在 FF++ 明显落后，说明骨干适配带来的源内收益没有同等迁移；若两边均落后，则原 B0 确实学到新判别能力。 |
| B02：保留寻址、学习证据写回 | 在给定本层输入时，由预训练 Q/K 决定每个 token 向哪里取信息。V 学取出的内容，O 学将其写入残差流，让后续 CLS 可读。CE 更新 24 对 V/O 和原头。与 B03 对比，测试保留预训练寻址函数是否比学习寻址更有利。 |
| B03：学习寻址、保留内容变换 | 反过来由可训练 Q/K 改变 token 之间的匹配，用固定 V/O 读取并写回信息。CE 更新 24 对 Q/K 和原头。若它优于 B02，说明限制内容变换而开放寻址更适合这批数据，不应反向宣称“冻结注意力更通用”。 |
| B04：全路径低秩协同 | 用与 B02/B03 相同的参数预算让四种投影各学 rank-2 更新，允许整个注意力计算共同调整。B04 胜过两个局部配置支持“覆盖计算链比集中容量重要”；若 B02 或 B03 胜出，才值得强调投影位置。 |

B00、B02–B04 的每个启用投影在推理时均可折叠为单矩阵；B01 直接用原始矩阵。位置对照不是从 B00 成品里关掉投影所得。

## 4. M 族：直接替换注意力矩阵的适配算法

M01、M02、M04–M06 均替换全部 96 个相同位置，不叠加 LoRA；保留并冻结原 Linear 的偏置。M03 是例外，它只开放 LN 和 head。固定 W₀=U diag(σ)Vᵀ，由同一份原始权重作 FP32 或 FP64 紧 SVD，奇异值降序；分解、随机基和配对表可跨种子共享，记录来源哈希。用 FP32 构造更新，避免在半精度求 SVD。

**M01/M02：Effort 是 B0 的外部方法对照，不是本地同名类。** d=1024 时冻结前 1023 项构成 W_main，最末一项初始化 u、s、v，训练 W=W_main+suvᵀ。初始化重构 W₀。每矩阵训练 2049 个标量，96 个共 196,704。上游发布实现 build_backbone 的 r=1023 指冻结秩，不是 LoRA 秩；其有效 get_losses 返回整批 CE，正则代码处于注释。M01 依据该有效路径，在本项目相同训练配方下做对照。记录移植所据上游版本。

M02 在 M01 上加入论文式正交约束与范数约束；为使本地实施唯一，E1119 定义为各矩阵等权平均，两个系数均取 1，不宣称是作者训练日志的系数。设 Û=[U_main,u]、V̂=[V_main,v]，
- Lorth=‖ÛᵀÛ−I‖²_F+‖V̂ᵀV̂−I‖²_F；
- Lnorm=abs(‖W‖²_F−‖W₀‖²_F)；L=CE+mean₉₆(Lorth+Lnorm)。
- 实现不必构造近千维 Gram：左项等价于 2‖U_mainᵀu‖²+(‖u‖²−1)²，右项同理。W_main 固定，范数可用 ‖W_main‖²+2s uᵀW_main v+s²‖u‖²‖v‖² 计算。

**M03：LN-only。** 冻结全部卷积、位置与 CLS 嵌入、注意力和 MLP；仅开放视觉塔实际存在的所有 LayerNorm γ/β（含前/后 LN）及分类头。LN 输出 γ⊙(x−μ)/sqrt(var+ε)+β；不改归一化算法或 ε。

**M04：S（调强度）。** W=W₀+U diag(σ⊙expm1(a))Vᵀ，a∈ℝᵈ，初始化零。等价于 U diag(σ⊙exp(a))Vᵀ；首式确保零更新时直接走 W₀。保留左右方向，可增强或削弱每一项。部署折叠成一个 Linear。

**M05：R（调方向）。** W=UR diag(σ)Vᵀ。R 由两轮 Givens 平面旋转按固定次序相乘：零基下第一轮 (0,1),(2,3),…；第二轮 (1,2),(3,4),…,(1023,0)。每轮 512 个独立角，初始全零；二维旋转采用标准 [cos,−sin;sin,cos]。实现可先得到无偏置的 W₀x，再在 U 坐标中旋转，最后加原 b；也可直接重构 W。Q/K/V/O、各层不共享角。对固定输入，线性无偏置项满足 ‖Wx‖=‖W₀x‖；并非整个 attention 输出的范数不变。96×1024 个角，与 M04 等参数。

**M06：随机基。** W=W₀+U_rand diag(σ⊙expm1(a))V_randᵀ；固定独立的 Haar 正交基（高斯矩阵 QR 并校正 R 对角符号），逐层逐投影固定种子，a=0。使用同一 σ 序列与同一参数化，使每个标量的初始权重导数 Frobenius 范数与 M04 相同。随机性只改变基，不改变初始 CLIP 或训练数据顺序。

M04/M05/M06 是研究对照，不以 SVD 或旋转本身为创新点；M01 和 M02 分别回答“发布代码式实现”和“加上明确正则”的效果，均用同一个 E1119 数据协议。参考：[Effort 论文](https://proceedings.mlr.press/v267/yan25b.html)、[上游有效训练代码](https://github.com/YZY-stack/Effort-AIGI-Detection/blob/main/DeepfakeBench/training/detectors/effort_detector.py)、[SVF](https://proceedings.neurips.cc/paper_files/paper/2022/hash/f3bfbd65743e60c685a3845bd61ce15f-Abstract-Conference.html)、[正交微调](https://proceedings.neurips.cc/paper_files/paper/2023/hash/faacb7a4827b4d51e201666b93ab5fa7-Abstract-Conference.html)、[GenD](https://openaccess.thecvf.com/content/WACV2026/html/Yermakov_Deepfake_Detection_that_Generalizes_Across_Benchmarks_WACV_2026_paper.html)。

| M01 | CE 的梯度只通过末奇异三元组及分类头。u、v 初始化于尾部方向，但随后可以转动，不把它们误锁在原来的一维空间。训练结束导出 W_main+suvᵀ 与原偏置。 | 对 B00 检验 Effort 式适配是否在本项目同一配方下获益；不是等参数比较。 |
| M02 | 同样学习 u、s、v，另用正交项惩罚尾部向量向冻结主基偏移，以范数项惩罚整体增益变化；正则不施加在头上。训练记录 CE、两项原始正则及各自加权贡献；推理仍只用一个权重矩阵。 | 与 M01 比较外库 AUC **以及**实际正交残差；残差变小但 AUC 不升，只说明约束生效。 |
| M03 | 用预训练 γ/β 初始化全部视觉 LN；训练中模型可按通道改增益和平移，使后续冻结 Q/K/V、MLP 得到不同输入。头部参数照常学习。部署直接保存更新后的 LN，无额外骨干路径。 | 若与矩阵方法同等或更优，结论是既有通道重标定已能支持检测，而非一定需要改权重子空间。 |
| M04 | 沿固定奇异基学习正的相对增益 exp(a)，整个更新可以是满秩，参数数量少不等于低秩。主干只允许重加权；保存每层学得的增益和折叠权重。 | 对 M05 判断强度与旋转的取舍，对 M06 判断预训练方向相对于任意低维基的作用。 |
| M05 | 学习两轮平面旋转角，取 R=R₂R₁，使第一轮先作用于向量；允许输出方向改变，但 WᵀW=W₀ᵀW₀。保存旋转配对顺序及角；导出时折叠 W，偏置后加。 | 若胜过 M04，支持跨层信息传递受益于这类输出重组；不等于所有正交变换都优于谱增益。 |
| M06 | 每个投影独立固化左右随机基，只有随机基中的方向系数和原头可学；部署将相应更新加回原矩阵，不能把 W₀ 替换成随机基重构。 | 若与 M04 相近而两者均赢 B00，证据偏向低维约束本身；只有 M04 更好才支持预训练基的额外价值。 |

**训练计算不必每步重建 96 个稠密权重。** M01/M02 的残余作用为 s·u·(vᵀx)。M04/M06 可直接计算基内坐标、逐元素缩放、再投回输出空间。M05 可按 x→Vᵀx→σ⊙坐标→两轮二维旋转→U 映射实现。冻结的 U/V 保存在同一分解资产中，训练梯度只进各方法登记的系数；推理可将各自的等效矩阵一次导出。训练权重和导出权重对应同一检测函数。

## 5. P 族：谁来定义受保护的输入方向

与 B00 同样的 96 个 r4 适配器。不训练第二分支。给投影输入 x 和列正交基 U∈ℝ^(1024×128)，计算：

    t = x − U(Uᵀx)
    y = W₀x + b + 4 B A t

只投影适配输入，不能把主路 W₀x 也投影掉。ΔWU=0 精确限制的是该线性层的直接更新，不是保证整张脸的最终表征不变。可将 A_eff=A−(AU)Uᵀ 折进更新，无须构造 1024×1024 投影矩阵。所有 P 行保持相同可训练参数和 k=128；投影基注册为 buffer。

**拟合基的统一口径。** 在首次训练前，预训练 CLIP 的 eval/no-grad 前向读取 FF++ train 已有的原生帧清单，使用项目已有确定性评测变换，仅用于离线估计 buffer；不更改训练 loader、不写新图。取各投影的实际输入：Q/K/V 用该块 attention 前 LN 输出，可共享一次统计；O 用合并多头后、out_proj 前的输入，另算，不能借用 Q/K 的基。所有 CLS 和 patch token 按相同位置等权参与。以源、帧、token 等权累计**未中心化**二阶矩 G=E[xxᵀ]，用前 128 个特征向量；此定义包含均值方向。跨帧/视频等权而不是让长视频支配 G。按统计点流式累计、必要时分层分块，不缓存全库 token。

**匹配真实/假/混合统计量，而非配对训练。** 限训练清单：按 FF++ 官方目标内容源 ID 建索引，保留真视频与至少一个对应伪造均有同数原生 8 帧的位置预算（不要求重新对齐的同一帧）；每源固定一真一假，假方法按四法循环、缺失时按固定次序轮换。用 SHA-256(UTF-8 源 ID) 的十六进制升序排序，取全部可用源的最大偶数 N。P01 用 N 个源的真视频，P03 用相同源的假视频，P04 在已指派的方法内作分层分配、真假各半且每源恰取一个视频（见下节），P02 用相同形状随机基。P02 采用确定性高斯 QR 前 k 列，Q/K/V 同输入共用基；O 独立。保存清单、各方法计数、各点样本数、特征谱和基摘要。**仅统计使用这个清单，各行的训练样本仍是完整原生训练集。**

预定比较：P01−B00 测实际增量；P01−P02 测数据方向相对任意约束的作用；P01−P03/P04 才检验真实侧的特殊作用。外部真图绝不用于估计 U。

### 四种方法各自拟合哪一个参考世界

令 M(x)=xxᵀ。某一统计点、某一源视频 i 的统计量为 Gᵢ=视频内平均帧、帧内平均 token 的 M(x)。先得各源的 Gᵢ，再取源均值。这样 257 个 token 不会被当作 257 个独立视频，短视频也不会被单纯堆帧所降权。

- **P01｜真实参考投影训练。** 对同一组内容源取真实视频，G_R=ΣᵢGᵢ(real)/N。固定前 128 维为真实参考，不训练原型或真实度头；全部真假样本照常用 CE 更新 4BA(I−UUᵀ) 与分类头。这个模型假设频繁承载真实人脸变化的方向值得少改，不是假设大特征值等于真实性。
- **P02｜随机保护训练。** 不拟合任何图像统计，生成与 P01 等维、等位置的随机正交基，使用相同训练算法和全体输入。它本身是一个随机受限的低秩检测器，而非随机打分。若 P01 与 P02 相当，就不能把泛化收益归于使用真图。
- **P03｜伪造参考投影训练。** 对相同内容源换用指定伪造视频计算 G_F。**保护**其主方向，而不是把假图投影能量当作伪造分数；每类训练样本仍参与 CE。与 P01 的差异只在参考分布。P03 若更好，真实分布未必是最佳的保护对象。
- **P04｜混合参考投影训练。** 每源只取一段视频，真/假各 N/2。先按已指派伪造方法分层，再在层内用固定源哈希排序、交替分配；各层奇数余数按固定方法顺序平衡到全局 N/2。这样不让“真假按奇偶”和“四种伪造循环”意外绑定。G_mix 用实际选中视频求均值，而不是混合模型输出。若 P04≈P01>P02，支持保护人脸激活方向，但“必须真图”缺乏增量。

**模型本身的机制读数。** 用于四行的保护矩阵始终在训练期间固定，梯度通过 (I−UUᵀ) 回到输入，不能 detach 整条增量。终评从 best 计算两项：每层 ‖ΔWU‖_F/(‖ΔW‖_F+ε) 检查结构性质；在八库现有帧上统计 E‖Uᵀx‖²/E‖x‖² 反映该参考覆盖了多少输入能量（真假分列，视频等权）。后者只读、不更新模型。若两基非常接近，P01/P03 相近也有具体解释，可用同层 ‖U_RᵀU_F‖²_F/128 描述重叠。四种模型均以合并后的 W₀+4BA_eff 独立部署。

## 6. T 族：改变层段的训练算法

B00 结构不变。h 为第 16 层输出，F_on 表示正常开启第 17–24 层 LoRA 的完整八块；F_off 是同样八块的预训练函数（同一份冻结 W₀，旁路 LoRA），含原残差/MLP。教师和学生比较的是**同一输入**穿过同一段的响应，而非两个不同深度的未经对齐的结果。采用段末、最终 post-LN 之前的完整序列，CLS 和 256 个 patch 等权，不另接 token 预测头。

给每个被约束样本定义相对均方差：

    D(x) = mean((F_on(h) − F_off(h))²) / (mean(F_off(h)²) + 1e−6)
    L = CE(完整 batch) + 1.0 × mean_selected(D)

均值跨 token 和通道，先逐样本归一化，再在所选样本间等权。为明确只约束段内适配，**该辅助项的两个 h 均 detach**；教师 no_grad、学生允许段内 LoRA 梯度。主 CE 始终使用正常可微分的原 24 层前向。可对约束样本重算 8 层；教师共享基座权重，不复制教师优化器。两次参考计算的 dropout 状态一致（原 CLIP attention/dropout 为零时直接复用）；不得关掉整段残差、LN 或 MLP。

- **T01**：约束当批所有真样本，标准 batch 即 10 个；假样本只参加 CE。
- **T02**：同批取与 T01 相同个数的样本；按训练步和独立固定 RNG 均匀无放回选一半真、一半假，奇数时多出的名额逐步交替；某类不足按另一类补足。训练 batch 本身不变。与 T01 的唯一区别是辅助项的样本类别。
- **T03**：从初始化就不在 17–24 层放适配器；1–16 层及原分类头正常训练。与推理时临时关闭 B00 末段是两项不同实验。

T01/T02 的参考计算只在训练时启用。终评均为单次标准骨干推理。T01 对 T02 区分类别特异性与普通约束；T01 对 T03 区分选择性保护与硬冻结。

### 三种完整末段训练算法

**T01（真实条件的末段保持）** 先在整批完成一次普通 B00 的 CE 前向；再从同一批选出真样本的 h.detach()，用学到的末段与固定末段各计算一次，反传相对误差。前 16 块只接受 CE，末 8 块接受 CE 与真图保持项，分类头只接受 CE。设计允许末段在伪造样本上重新组织信息，同时不强迫训练后的真实输出变成单个中心。测量源内和外库真/假分开的 D(x)，并与 T02 同口径比较；外库 D 只解释结果。

**T02（类别无关的混合保持）** 完整检测函数与 T01 相同，教师也是同一输入上的预训练末段，但参考集合在既有训练批中跨类别取样。它学习的是“对人脸样本普遍保守”的末段。约束预算、归一化、权重、梯度边界和所有分类样本不变。T01 若只比 B00 好、不比 T02 好，不能把收益称为真实侧特异性。

**T03（可学习前段＋固定后段）** 前 16 层适配器必须学会输出能被固定后 8 层解释的表示，而不是用另一个读出替代末段。CE 须穿过冻结末段回到前段，**冻结权重不等于对该段使用 no_grad**。骨干可训练参数为 16×4×8192=524,288，不含头；推理仍遍历 24 块。T01 与 T03 比较的是整套选择性保持策略和硬冻结策略，不是等参数对照。若 T03 即可达到同样跨库表现，直接采用固定末段的简单结构。

## 7. I 族：相邻层之间改变前向读取或反向传递

对相邻层 j,j+1，输入 h 进入前层；v=F_on,j(h)，u=F_off,j(h)，其中 F_off 只旁路第 j 块的四个适配器，其他块不受影响。记 n_v=LN_attn,j+1(v)，n_u=LN_attn,j+1(u)。对第 j+1 层的 p∈{Q,K,V} 用：

| 组 | 投影输出（含偏置一次） | 参考支路和梯度 |
|---|---|---|
| B00 | Wₚ n_v+bₚ+4BₚAₚ n_v | 标准前向和反传 |
| I01/I02 | Wₚ n_v+bₚ+4BₚAₚ n_u | 参考读数与 v 来自同一 h；u 对 h 保持可导，不对前层 LoRA 可导 |
| I03 | Wₚ n_v+bₚ+4BₚAₚ stopgrad(n_v) | 数值等于标准前向；只切断该适配输入上的反传，A、B 及基座主路径的梯度不切断 |

I01/I03 的 j=23；I02 的 j=15。Q/K/V 进入原缩放、softmax 和 value 聚合；后一层 O 投影仍是标准单输入 LoRA；后一层 attention/MLP 的主残差继续使用 v。不要为得到 u 暂时就地 merge/unmerge 共享权重；同一个 block 实现显式 adapter 开关，在同一训练图中完成两路计算。u 不是全网络无适配的 CLIP 输出。I01/I02 中不得用 no_grad 包裹整个 u，否则同时改变了早期块的梯度，和 I03 的解释会混杂。

I01/I02 训练和推理均需多计算一个完整块，不增加参数；该层双输入的 Q/K/V 不能合成一个标准 Linear。I03 没有额外推理算量，能按 B00 正常合并。记录实际峰值显存、每轮耗时和固定 batch 前向耗时。比较 I01−B00、I02−I01、I03−B00、I01−I03；最后一组比较两种干预整体效果，不将其差值解释为严格独立的纯前向因果量。

### 由完整块构成检测器，而不是末层插入一个辅助头

**I01（末对分流）**：前 22 块用普通联合适配提取表示，第 23 块生成 v、u，第 24 块主干读取 v，Q/K/V 增量读取 u，最终用原 post-LN 和头判别。其假设是：最后一次适配不必直接读取倒数第二层刚形成的任务修正，仍能利用完整主路作判断。

**I02（中对分流）**：前 14 块普通，第 15→16 块分流，17–24 块普通。与 I01 的区别不止于数值层号：中途形成的表示此后还能经过八个正常适配块。它回答“早一点隔离一次，后续计算会保持还是吸收其影响”。两个方法都单独由 CE 端到端训练。

**I03（末对梯度解耦）**：在前向里第 24 层主路和增量都看到完整的 v。反传时，Q/K/V 增量只向自己的 A/B 送梯度，不通过其输入向第 23 层送梯度。上游仍接收来自冻结 Q/K/V 权重所构成的可微主路、O/MLP 及残差的梯度。因此其训练不是分层贪心训练，也不是冻结第 23 层。部署和 B00 同构。这是与 I01 对照的一种完整优化算法。

### I04｜全深度配对前向分流

**研究问题。** 单独约束最后两个块可能只改变分类头附近的决策。I04 把一种固定的传递规则作用于从输入到输出的整个骨干：每个奇数块可以写入任务信息；配对的偶数块让原始主路继续使用这个结果，但自己的 Q/K/V 增量从“该次写入之前的参考响应”中取输入。它限制的是配对内的直接串联，前面各对已经建立的表示仍进入下一对。

**前向递推。** 将 24 块分成 (1,2),(3,4),…,(23,24) 共 12 个不重叠的对。H₀ 是正常的 CLIP 输入 token。第 t 对的入口是上一对的唯一输出 H₂ₜ₋₂，计算：

    h = H[2t−2]
    v = odd_block(h, adapter=on)
    u = odd_block(h, adapter=off)                   # 只旁路本奇数块的四个增量
    Q,K,V = base_qkv(LN_even(v)) + delta_qkv(LN_even(u))
    H[2t] = even_block_finish(residual=v, Q=Q, K=K, V=V)

even_block_finish 保留原多头 attention、标准 O 适配、两条残差及 MLP；base_qkv 含偏置，delta_qkv 不含偏置。从偶数块出去后只保留一个 H₂ₜ 前进；u **不**作为第二条流传播。禁止将骨干改成两个完整 CLIP，也不要改成所有相邻边 (1→2,2→3,…) 都分流，这两者不是本方法。全 96 处 r4 和原头均可学，目标只用 CE；参考奇数块的 W₀ 不可训练，但 u 对 h 可导。来自主路和参考路的输入梯度在 h 处相加。

**部署与检验。** 训练和推理均执行 12 次奇数主块、12 次奇数参考块、12 次偶数块，共 36 次块计算；这不是 36 层深度，也不是实际延迟固定增加 50%。可在每对内重新计算参考值以节省保存的激活，不能改变梯度或降低历史 batch。与 I01/I02 比较“全骨干重复使用规则”是否比单位置干预更有用；与 B00 比较该结构的总增益，连同实测延迟一起报告。如果局部版本有效而全深度变差，说明全局重复切断也损伤了有用的跨层协作。

### I05｜全深度配对反向解耦

**研究问题。** 是否可以保留完整的层间前向表达能力，只限制“当前层的适配要求上一层为自己生产特征”的梯度通道？I05 使用与 I04 完全相同的 12 对位置，但每个奇数块只计算一次；偶数块 Q/K/V 增量使用数值相同、反传被截断的输入。

    v = odd_block(H[2t−2], adapter=on)
    n = LN_even(v)
    Q,K,V = base_qkv(n) + delta_qkv(stopgrad(n))
    H[2t] = even_block_finish(residual=v, Q=Q, K=K, V=V)

用单个投影说明：若上游梯度为 g，普通 LoRA 对 n 给出 W₀ᵀg+ΔWᵀg；I05 在这条投影对 n 仅给出 W₀ᵀg，而 A/B 仍从 g 与 n 更新。该规则只用于偶数块的 Q/K/V；奇数块、偶数块 O、MLP、残差和分类头维持原反传。由此所有奇数块适配器仍然受最终 CE 监督，没有一半骨干被意外冻结。

**部署与检验。** 对同一套固定权重，I05 与普通 LoRA 前向数值相同；不同的是训练后得到的权重。部署能合并全部适配矩阵，正常 24 次块计算。I05 对 I03 检验全深度与末对训练的区别；若 I05 与 I04 有近似跨库表现，I05 无参考块推理成本。若只有 I04 提升，则仅截断这条梯度不足以复现前向分流的效果。

### 层间方法的共同机制测量

在 best 权重的既有评测帧上，用同一对输入比较第 j+1 块 Q/K/V 增量读取实际 v 与参考 u 时的差异：对各投影计算 E‖ΔW(n_v−n_u)‖² / (E‖ΔW n_v‖²+ε)，先按 token/帧/视频等权取均值，再取比值，ε=1e−8。B00、I01–I05 在相同配对位置报告，真假分开；ΔW=0 或分母极小时同时报告未经归一化的两个能量。这个量衡量串联适配有多少信号可用，而不是图像真实性分数；八库正式预测仍来自原头。I03/I05 的 u 只在离线解释时计算，不计入部署前向。报告模型精度、每视频耗时和峰值显存，分别回答“是否更准”与“额外计算是否值得”。

## 8. 随完整训练一起交付的层级分析

这些是训练产物上的正式测量，不新增输入、不作阶段门槛、不把探针接入部署模型。只依赖 checkpoint 的任务在对应权重就绪后自动运行，无需等汇总表或人工确认。

| 分析 | 固定对象与计算 | 输出 |
|---|---|---|
| D01：信息何时出现 | 原始 CLIP 与两种子 B00 的 epoch 0/5/10 和 best；取 block 4/8/12/16/20/24 的末端 CLS（post-LN 前，不把最后一层 pooler 混入）；每个模型/层单独用完整 FF++ train 的原生帧特征拟合线性探针 | 每层每时点八库视频 AUC，和同层原始 CLIP 作差；表示可读出性，不等同于原头实际依赖 |
| D02：原头用到了哪段适配 | 同一批 B00 权重保留原头、分别关闭 1–8、9–16、17–24 的 LoRA，再加未干预输出；关闭的是增量，不删除 Transformer 块 | 各库成对原头分数、AUC 与变化；保留 seed/checkpoint/段名 |
| D03：真实表征是否得到保护 | B00、P01–04、T01–03 和预训练 CLIP，在最终 best 的同一组原生视频、同一帧位比较 block 8/16/24 的 CLS；对预训练参考算 1−cos(h,h₀) | 对每库按真假分别聚合：帧→视频均值→库均值；与外部视频 AUC 并列，不能以变化小代替鉴别成绩 |

D01 固定使用有截距的 L2 LogisticRegression（L-BFGS，C=1，max_iter=1000）；标准化只拟合 FF++ train；输出假类概率。不为每层选超参。视频划分沿用原 split，探针只用训练标签；八库标签只用于最终计分，不用于选择层或训练行。若 best 与某个 epoch 为同一权重，可按 SHA 复用特征。D02 的同一次干预不要求重训。D01/D03 按层流式导出 CLS，不为分析保存所有 patch 激活。

## 9. 实现落点、排队与交付接口

**已有、可复用的入口**（相对 DeepfakeBench 根）：training/detectors/effort_detector.py 的 build_backbone / features / classifier；training/train.py 与已有 Trainer；experiments/run_e1115.py 中对 B0_NATIVE 的配置分发、评测口径和导出；experiments/e1111_runner.py 与现有路径映射。不要运行 E1115 整个入口来代替 E1119，也不要改原 B0 的默认行为。

**方法实现边界**：以统一的 E1119 detector 接口连接原 Trainer；每个 ID 都能独立构建、训练、从自己的 checkpoint 恢复并做八库推理。各方法共享确实相同的运算，不以事后开关或替换已训练权重代替从头训练。B00 直接走原生代码；其他行在原始 CLIP 导入后、优化器创建前决定适配形式。不要先实例化 B00 再让其按名称冻结所有非 LoRA 参数，否则 M 族会看似训练而实际不更新。保留完整训练配置、可训练参数名/形状/总数和 checkpoint 加载所需的基、角度、层号。初始化相同不等于强制训练后头部相同。

**全量调度契约（规格，不是当前已有命令）。** 实现后默认等价于：

    RUN_ALL = product([B00..B04, M01..M06, P01..P04, T01..T03, I01..I05], [1024,1025])
    每一个 (arm,seed): 原初始化 → 11个完整epoch → best的八库统一评测 → 保存逐视频分数
    只读统计资产 → P/M所需行；权重就绪 → D01/D02/D03；最后汇总全部状态

SVD 和各统计来源的 P 族基分别计算一次，随机资产由固定资产种子 1119 派生（以投影名与资产类型区分），跨训练种子复用，完整收集源样本，不需另做开发集实验。B/M/P/T/I 在依赖就绪时独立排卡；有几张卡就消费几个训练任务；依赖是“权重或统计文件存在”，不是“上一组效果好”。每个任务独立进程，复用现有 server 数据根、索引、CLIP 路径和训练环境。缺资源时等待卡位；训练失败保留错误并继续派发其余独立任务；续跑按 (arm,seed,配置哈希,数据/预训练标识) 找未完成项。不覆盖旧结果，不以其他 checkpoint 冒充缺失行。

### 运行入口

在服务器的 `DeepfakeBench` 根目录执行：

```bash
python experiments/run_e1119.py --plan
python experiments/run_e1119.py --gpus 0,1
```

`--plan` 只输出依赖图。正式命令提交全部 46 次训练及离线测量，省略 `--gpus` 时使用全部可见卡。可用 `--rgb_root`、`--dataset_json_folder`、`--clip_pretrained_path` 指向原始资源。用同一命令续跑时，按输入、配置和源码指纹找到原队列，沿用完成项并为失败或缺库任务保留新的尝试目录。

结果默认写入 `experiment_results/E1119/<运行指纹>/`。主表为 `main_seed1024.csv`，复现附表为 `replication.csv`，逐库成绩为 `datasets.csv`，分析入口为 `analyses.csv`。可通过 `--historical_b0` 传入含 `seed`、`source`、`independent_video_auc_mean_fullpath` 和 `input_identity` 的已核实历史记录。历史输入指纹匹配时计算历史差值。

同一源码的 E1115 B0_NATIVE 实际配置决定 LoRA 初始化。当前本地 `effort.yaml` 启用 `loralib`，因此 B00 和其他 LoRA 行按该实现初始化。训练记录中的头部权重、loader RNG 和原生清单顺序指纹可用于逐行核对。

## 10. 最终评测与结果表

八库固定：WDF、FFIW、CDF-v2、DFD、DFDC、DFDCP、DeeperForensics、FF++。沿用原测试 8 帧、无增强、无多裁剪。单帧存原头 softmax(fake)；按数据集内**完整视频路径**分组平均帧概率得到视频分数，再按视频计算 ROC-AUC。不要按 basename 混视频，不用“先平均 logits 后 softmax”替代。主指标为六个独立外库 video-AUC 的等权均值（排除 FF++、CDF-v2），另报每库、外部七库均值、frame AUC。缺库时完整均值为空而不是改分母。按百分点给同种子相对 B00 的差值，再报两种子均值和各自原值；两种子不是显著性证明。已有历史 B0 数字不直接填入本组。

每个 arm 输出：配置及固定资产标识、种子、可训练参数量、训练耗时、峰值显存、best 的 epoch/step 和选点指标、逐帧与逐视频预测、八库指标。全量摘要含 46 行 (arm,seed) 和 23 行跨种子表，记录成功、失败、缺库；D01–03 放独立表，不能当成新的主模型行。核心对照预先指定，不因某组好而改排序口径：
- 结构位置与容量：B02/B03/B04 对 B00，三者之间等参数对照。
- 矩阵：M01 对 B00，M02 对 M01；M04 对 M05/M06，三者各 98,304 个适配参数；同时对 B00/M03。M04/M05 的优化尺度和参数约束不同，不能把差异全归于严格唯一机制。
- 真实参考：P01 对 P02/P03/P04；层段：T01 对 T02/T03；信息传递：I01 对 I02/I03，I04 对 I01/I02/B00，I05 对 I03/B00，I04 对 I05。均保留同种子 B00 原头结果。
- 在外部视频 AUC 上升时，查看逐库变化及真实视频分数分布，区分转移能力增强与个别库拉高均值。讨论 FF++ 特有线索或“真图通用特征”时，用 P/T 的类别对照和 D 族结果支撑，而不是给 SVD 主方向直接贴上“真实性”标签。

### 形成科研结论的规则

保留每个方法每个种子的八库完整成绩，不按主表名次回头选层、改系数或删结果。表中显示 1024 历史主口径；1025 单独报告，再给每种子相对于**同种子 B00**的六库宏平均差。把“某方法优于 B00”和“某特定设计是原因”拆开报告：

| 欲回答的问题 | 除 B00 外最有解释力的比较 | 如何处理反例 |
|---|---|---|
| 是否一定要重学注意力匹配？ | B02 对 B03、B04 | 同容量结果接近，则优先解释为容量变化，不给某投影赋予“通用性”。 |
| 是否需要保住预训练的谱方向？ | M04 对 M05、M06；M02 对 M01；M03 作为无矩阵适配参照 | 若随机基或 LN 同样好，谱分解不是已证明的必要成分。 |
| 真图在定义保护方向上是否特殊？ | P01 对 P02/P03/P04，并列基的重叠与独立外库覆盖能量 | 如果真、假、混合都胜过随机，结论改为“激活定义的方向有价值”，而不是“真图独有”。 |
| 保住真实样本的末段变换是否有用？ | T01 对 T02、T03，连同按类分开的段输出漂移 | 漂移小但外部 AUC 不升，只支持“保住了响应”，不支持“提高通用检测”。 |
| 泛化差异来自层间怎样传值或传梯度？ | I04 对 I05、B00，I04 对 I01/I02，I05 对 I03 | 全深度不如单位置就报告覆盖范围的代价；对 I04/I05，不以参数相同代替推理成本相同。 |

对上述预定差值可直接使用已保存的逐视频预测给出配对区间：在每个库内按真假分层、以完整视频为单位有放回重采样，两模型使用相同抽样索引，各库重算 AUC 后等权取六库差；固定 2,000 次，报告 2.5% 和 97.5% 分位。区间按训练种子分别计算，描述给定 checkpoint 的视频抽样不确定性，不把两个种子拼成双倍测试样本；不替换历史主列，也不据此决定后续配置是否执行。

**范围落实。** 真图统计和冻结模型探针使用现有输入；不恢复额外训练视图、重编码配对、重采样、时序教师、patch/CLS 辅助预测头、外置分数融合、门控校准或目标域适配。前述只是相关背景的模型和文献不逐篇复现。E1119 的“全量”就是上表全部独立模型训练、两种子和预定测量，无预实验。
