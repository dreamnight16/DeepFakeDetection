## Ownership and contracts

1. **Data:** `experiments/e1005_data.py`, `tests/test_e1005_data.py`. Stdlib metadata/manifest layer; lazy torch/PIL for strict datasets. Public `build_manifest(metadata,dataset,split,label_dict,compression='c23',sampling='uniform_metadata8',frames=8)` returns list of video records with `video_id,label,label_name,frames,indices,all_frames,all_indices,method,target_id,source_id,masks`. Public `build_pair_candidates(train_records,min_frames=2)` -> `{pairs, exclusions}`; each pair `{pair_id,method,real,fake,common_indices}` where real/fake are video records. `verified_pairs(candidates,audit)` validates explicit audit receipt and matching identities/metadata; never treats filenames as proof of aligned time/face. `build_episodes(pairs,steps,seed=1024,frames=2)` creates fixed episodes,4distincttarget sources and4methods per episode. `VideoDataset(records,reader,frames=8)` yields image[T,C,H,W],mask[T],label,path list,video_id; `collate_videos` -> batched equivalents. `PairDataset(episodes,reader,mean,std,independent_nuisance=False)` yields videos[B=8,V=2,T=2,C,H,W],valid_mask[B,V,T], labels[B] alternating0/1,methods[B] (fake0..3/real-1),conditions[B,V],real_indices[4],fake_indices[4], paths/video IDs. Batch-global nuisance for M/S; C2 shares nuisance separately per class. `collate_pairs` initially supports batch_size1 because episode already effective32 images. Reader(path) -> unnormalized RGB CHW float0..1; strict errors propagated. Optional registered mask/native map readers, path canonicalization and crop asset validation. Full source/target/split leaks rejected. Test-first.

2. **Objectives:** `training/detectors/e1005_objectives.py`, `tests/test_e1005_objectives.py`. Pure torch. Public `video_log_odds(logits,mask)` consumes [B,V,T,2] and bool[B,V,T], returns u[B,V] stable logit(mean sigmoid(logitdiff)); `compute_losses(output,batch,objective,teacher=None,keep_weight=.1,tau=.5,rank_weight=1.,metric=False,spatial_target=None)` where output has logits[B,V,T,2], optional features[B,V,T,D], mask_logits(flatvalid...), teacher logits same shape. Batch labels/methods/conditions and fixed matched indices as above. Objective flags video/frame,rank none/matched/shuffled,keep,method_risk,nuisance_risk, independent_nuisance; return overall + diagnostics. Shuffle derangement deterministic given batch `shuffle_indices` (provided episode) and K independently all16real×fake. Losses train-only. Exact hand-computed/gradient/padding tests; no script imports.

3. **Models:** `training/detectors/e1005_models.py`, `tests/test_e1005_models.py`. Pure torch module; dynamic-load sibling e1002_matrix for plain zero-residual if needed. Public `build_model(base,spec,pretrained=None,options=None)` returns E1005Model; `forward(data,inference=False)` accepts dict image[N,C,H,W], optional aux_image[N,C,H,W]; returns cls[N,2],prob[N],feat[N,D], optional mask_logits[N,1,h,w]. `trainable_parameters()`; settings serializable. Scope H,L,J,reset_head,new_residual,residual_head; cold R1/R2 pristine pretrained Effort; R3 LN+L2+head. D1–D4 patch-only adapters after configurable blocks; D5–D8 independent pretrained/B0 feature delta; E CNN pixel injection and strict aux_image input. Never retain/register mutable source teacher; deep copies independent. Options local_layers(4,8,12),late_layers(16,20,22),pixel_layers(8,12),adapter_width32 and scopes; tiny tests pass explicit overrides. D no detach inside trainable student path; immutable B0 anchor forward no_grad. Cold branches require pristine model supplied, no silent reuse of fitted LoRA. Small snapshots will save all trainable state and new-module buffers only, reconstruction binds immutable source identities. Test-first including custom/loralib trained LoRA, initial equivalence, gradient updates and source preservation.

4. **Coordinator:** owns `experiments/e1005_protocol.py`, `experiments/run_e1005.py`, `experiments/e1005_reporting.py`, `tests/test_e1005.py`, `experiments/E1005_README.md`, numbering additions to design. Dependency-free catalog/dry-run; audit/preflight; strict B0 source resolve; resources/paired receipt gating; training all eligible arms; selectorsS1/S2/S3/S4 on same snapshots; automatic G34 champion-derivedablation and G35 chosen objective; no historical-domain winner switching. Calibration/exports/paired ranking improvements/champion criterion. Progress flushed stdout plus run.log/progress.json, original B0 state/file hashes, resumable signature-bound arm reuse, trained-parameters-only checkpoints. Repeat same seed/config only. No new seed grid, no test labels in loss/selection.
