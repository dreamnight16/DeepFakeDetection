# E1002 Implementation Plan

> **For agentic workers:** Use focused independent implementation tasks, followed by Python/code review and integration verification. Steps use checkbox syntax.

**Goal:** A single runnable E1002 command covering four structural routes and their controls.

**Architecture:** Three independently owned torch modules feed one strict experiment orchestrator. Frozen B0 is the reference; matrix arms own copies. No legacy experiment code is modified.

**Tech Stack:** Python, PyTorch, existing CLIP/loralib, NumPy and project metadata loaders. No new Mamba dependency.

**Spec:** ../specs/2026-10-02-e1002-design.md

## Global Constraints

- Keep B0 checkpoint, E0924 and E1001 unchanged.
- Defaults: 13 arms, 10 epochs, seed1024, hidden64, rank4, last4 matrix layers, preserve-top32.
- FF++ train supervision and official val video-AUC selection; no final test selection.
- Checkpoint identity, strict image reads, numeric frame order, finite values and padding masks fail closed.

## Review Focus

- Existing fitted loralib weights must be preserved before new matrix updates.
- Video frame indices must be numeric; metadata labels must agree across a clip.
- Padding cannot affect temporal scores or gradients.
- Environment loss must supervise nuisance to avoid trivial all-zero disentanglement.
- Independent arm errors must preserve completed results, return failure and leave B0 unchanged.

## Execution decisions

User requested implementation of all four routes. Work in the shared checkout with additive E1002 filenames and no edits to pre-existing model/experiment code. Parallel tasks have disjoint ownership; coordinator owns integration. No push, merge, deployment or remote GPU launch is implicit in this local implementation.
