# E1002: four structural research routes

User authorization: “都试一试，作为E1002”. This implements runnable experiments; it does not claim a completed GPU experiment or a reproduced published method.

## Protocol

Reuse the successful E0924/G26_B0 checkpoint and its preprocessing. Never overwrite B0 or previous experiment outputs. Thirteen independently seeded arms: CLS_HEAD, PATCH_MEAN, COV_GLOBAL, COV_REGIONAL; MATRIX_LORA, MATRIX_SVD_TAIL, MATRIX_SVFT; ENV_CONTROL, ENV_ORTH; TEMP_MEAN, TEMP_DIFF, TEMP_TCN, TEMP_SSM.

Readout and environment arms freeze B0 and consume detached final patch/CLS features. Matrix arms deep-copy B0, freeze its fitted adapters, add zero-initialized updates to the last four blocks' Q/K/V/out projections and train their copied classifier. They are warm-start adaptation experiments, not literal Effort/SVFT reproductions. Temporal arms process ordered video clips using a frozen B0. TEMP_SSM is a small torch-native selective diagonal state-space readout, not the official Mamba architecture.

All arms train FF++ train, select checkpoints using FF++ official val (source-ID-disjoint from train/test) video AUC, then evaluate the eight existing test datasets. CDF is a reported dataset, not a new checkpoint-selection domain; the reused B0 was previously selected on CDF. No test labels select arms, thresholds, or hyperparameters. Fixed 0.5 scores plus a threshold calibrated for 5% real-video FPR on val; report video AUC/AP, FPR/FNR and TPR at the val threshold. The empirical val FPR can be below 5% because of ties.

Training budget defaults to 10 epochs and seed 1024, with multiple seeds CLI supported. Default heads dim64, rank4, four matrix layers, preserve-top32. Report trainable parameter counts, optimizer steps, seconds; budgets are not claimed capacity matched. All checkpoints bind B0 SHA256 and settings. Strict image errors never substitute samples. Outputs are atomic; failures are explicit; baseline state/file hashes are checked after arms. Temporal sorting uses numeric filename frame indices, records sampling and never calls sampled frames adjacent originals.

## Module boundaries

- `e1002_heads.py`: `FeatureReadout(kind, feature_dim, hidden_dim=64)` with `forward(cls, patches)` -> [B,2]; kinds cls/mean/cov/regional. `EnvironmentReadout(feature_dim, hidden_dim=64)` with `forward(cls)` -> dict logits [B,2], nuisance_logits [B,4], forgery/nuisance [B,D]; `environment_loss(output, labels, nuisance_labels, orth_weight)` -> loss dict. Freeze/detach input at boundary; nuisance is known photometric intervention, not measured person identity.
- `e1002_matrix.py`: `MatrixAdaptation(base, kind, rank=4, last_layers=4, preserve_top=32)`; kinds lora/svd_tail/svft; deep-copy immutable base, zero init exact scores in eval, `forward(data, inference=False)` returns normal detector output; `trainable_parameters()` supplies new update parameters and copied head. Independently test original B0 state remains unchanged.
- `e1002_temporal.py`: `TemporalReadout(kind, feature_dim, hidden_dim=64)`; kinds mean/diff/tcn/ssm; `forward(features, mask)` -> [B,2], features [B,T,D], bool prefix-valid mask [B,T]; ignores padding, validates nonempty clips, detaches B0 features, permits sequence-order sensitivity except mean.
- `e1002_data.py`: feature extraction wrapper and strict ordered video loaders, independent inference B0 scores; numeric filename sorting, metadata-derived video identity and label validation, padding mask, train-only sampler.
- `run_e1002.py`: lazy CLI, preflight, complete per-arm train/reload/export flow, immutable baseline validation, standardized manifests/results. Reuse e1001 low-level source/preflight/hash/strict loader helpers without altering their behavior.

## Validation

Hand-checked covariance, immutable-input gradients and padded-sequence invariants; effective pretrained LoRA weight preservation and spectral constraints; malformed settings/checkpoints and frame labels; tiny real CLIP end-to-end train/select/reload/export covering every route. Run the existing project suite. Real server data/CUDA remain explicitly unverified unless actually run.
